# Forgepoint Industrial Services — FireWorks demo

Fictional, six-page industrial/commercial services template. Includes capabilities, industries, safety and qualification framework, illustrative project-history structure, and a proposal preview. No real company, projects, qualifications, safety performance, or emergency service is claimed.

`npm run check` validates page output and demo safety. `npm run build` writes static pages to `dist/` for Vercel.

The proposal form validates locally only. It does not submit, upload, persist, or contact anyone. Real procurement intake requires a client-approved secure provider, retention and consent terms, and end-to-end testing.
